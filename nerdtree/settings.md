# NERDTree - Settings

Show hidden files
```vim
let NERDTreeShowHidden=1
```

Show NERDTree bookmarks
```vim
Let NERDTreeShowBookmarks=1
```

Show line numbering (like via "set number" for vim itself)
```vim
let NERDTreeShowLineNumbers=1
```

Hide "Bookmarks" label & help(?) text
```vim
let NERDTreeMinimalUI=1
```
